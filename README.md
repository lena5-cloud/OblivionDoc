# OblivionDoc

Умный архив документов с автоматическим управлением сроками хранения.

OblivionDoc — веб-приложение для хранения документов, контроля сроков их хранения и автоматического выполнения заданного действия после истечения срока.

## О проекте

OblivionDoc создан для автоматизации работы с документами, имеющими ограниченный срок хранения. Пользователь может загрузить документ, указать его название, срок хранения и выбрать действие, которое необходимо выполнить после его окончания: архивирование или удаление.

Система автоматически отслеживает сроки хранения документов и выполняет выбранное действие, что позволяет пользователю не контролировать каждый документ вручную. Все основные операции фиксируются в журнале действий, благодаря чему можно отслеживать историю работы с документами.

В приложении реализованы регистрация и авторизация пользователей, восстановление пароля по электронной почте, загрузка, редактирование, скачивание и ручное удаление документов, а также автоматическая обработка документов с истёкшим сроком хранения.

Проект разработан в рамках направления информационной безопасности и ориентирован на повышение удобства, контроля и автоматизации работы с документами.

## Возможности

- регистрация и авторизация пользователей;
- безопасное хранение паролей;
- восстановление пароля по электронной почте;
- загрузка документов;
- установка срока хранения документа;
- автоматическое архивирование документа;
- автоматическое удаление документа;
- редактирование информации о документе;
- скачивание документов;
- ручное удаление документов;
- журнал действий с документами;
- автоматический планировщик обработки истёкших документов;
- ограничение размера загружаемого файла;
- поддержка основных форматов документов и изображений.
